## 快速查找

1. **运行数据** → `data/`：所有运行输出与标准化数据；程序主读写数据根。
2. **钱包事实数据** → `data/source_wallet_bot/`：钱包采集、标准化、筹码事实、同源组、资金路径、地址历史。
3. **结构推断数据** → `data/intel_bot/`：主导侧行为动机推断、反证、量化分、结构结论。
4. **报告中心** → `reports/`：人类可读报告、审计报告、汇总报告。
5. **方法轮** → `research_loop/`：计划、checkpoint、验收、blocker、长任务状态、任务包。
6. **方法论资产库** → `research_loop/methodology/`：方法护照、判断规则、反证规则、统计模型、字段映射、审计规则。
7. **代码模块** → `modules/`：功能代码主目录，包括 source_wallet_bot、intel_bot、review_ops_bot、wallet_structure。
8. **测试** → `tests/`：自动化测试。
9. **字段合同** → `schemas/`：系统级 shared schema。
10. **交接合约** → `contracts/`：跨 Bot / shared 合同。
11. **导入暂存** → `imports/`：外部资料、旧包、zip、中文旧资料进入正式吸收前的 staging。
12. **旧路径兼容** → `legacy_compat/`：manifest、path map、read fallback；记录旧路径到新路径映射。
13. **系统文档** → `docs/`：系统宪法、目录规则、工程说明。
14. **工具脚本** → `tools/`：项目级工具脚本。
15. **配置** → `config/`：配置文件。
16. **旧混合运行区** → `data/gmgn_candidates_live_run/`：历史混合 runtime：GMGN、paper、dashboard、state、token 输出等。
17. **旧中文结构资料** → `结构分析/`：旧结构分析资料/备份。
18. **旧中文钱包资料** → `钱包数据分析/`：旧钱包数据分析资料/备份。
