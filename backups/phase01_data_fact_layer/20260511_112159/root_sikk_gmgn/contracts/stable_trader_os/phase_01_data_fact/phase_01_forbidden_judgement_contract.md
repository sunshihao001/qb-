# Phase 01 Forbidden Judgement Contract

Phase 01 是数据事实层，不是交易解释层。

## 禁止输出

- 禁止输出“确定庄家”。
- 禁止输出“可以买”。
- 禁止输出“强烈建议买入”。
- 禁止输出“吸筹完成”。
- 禁止输出“派发完成”。
- 禁止输出“主力控盘”。
- 禁止输出“二段扩张概率高”。
- 禁止输出任何真实交易执行建议。

## 允许输出

- 字段存在 / 缺失。
- 来源优先级。
- 数据质量分。
- PASS / PASS_WITH_WARNING / PAUSE / BLOCK。
- restricted_models。
- Phase 01 到 Phase 02 的 handoff packet。
