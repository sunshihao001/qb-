# SIKK-GMGN / SIKK-SOL

这是一个基于 GMGN 的 Solana 结构情报与纸面验证项目。

## 主要目标
- 新币候选筛选
- 早期结构钱包分析
- 钱包实体画像与关系边分析
- 钱包结构门禁与纸面复盘
- 专业静态控制台与自动化工作流

## 安全边界
- 不执行真实 swap
- 不读取或保存私钥
- 不自动签名或广播
- 默认纸面验证 / 只读分析

当前仓库包含：
- 核心 Python 模块
- 测试用例
- 方法文档
- 纸面运行输出与复盘资料
