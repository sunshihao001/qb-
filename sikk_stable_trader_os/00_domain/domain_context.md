# Domain Plane 领域上下文压缩包

HER 运行任何 Data / Evidence / Scenario / Strategy 前必须先读取本文件。

## 定位
Domain Plane 不是策略说明，也不是数据采集层。它是领域语义总控层，回答：系统到底在判断什么。

## 边界
- 允许：定义领域对象、钱包角色、生命周期、场景、证据、反证、硬否定、市值上下文、推理边界、字段需求、handoff 合约。
- 禁止：直接生成买入信号、直接执行交易、直接采集链上数据、把疑似主导侧说成确定庄家、在关键字段缺失时强判断。

## 标准表达
使用“疑似主导侧”“结构侧”“筹码控制权可能仍部分保留”“派发进度尚未完成”“证据不足，禁止强判断”。

## 当前裁决
Domain Plane 可作为 P03 Data Plane 的字段需求输入，但仍带非阻断缺口：阈值、样本、刷量识别、市值边界、同源归因需要后续校准。
