# K00 Context Pack — HER System Construction Document Intake Prompt v2.0

## Why this phase exists
The uploaded material is a system construction prompt. It must be preserved and converted into file-backed K00 assets before any downstream phase is considered.

## What this phase does not do
- No direct PXX/IXX entry
- No runner start
- No paper/live runtime
- No production rule changes
- No chat-only summary

## What this phase must do
- Preserve raw source
- Register the source
- Build document passport and corpus index
- Map affected planes and phases
- Detect and preserve gaps
- Create a phase task package
- Write phase state, acceptance, handoff, and trace/audit artifacts

## Completion rule
K00 is complete only when the file-backed package exists and the handoff is recorded. Non-blocking gaps must remain visible.
