2. Register the source.
3. Generate the passport.
4. Build corpus index.
5. Map system planes and phases.
6. Detect gaps.
7. Write task package files.
8. Write phase state.
9. Run K00 acceptance.
10. Write handoff packet.
11. Write trace/audit record.
12. Stop at K00 boundary.
