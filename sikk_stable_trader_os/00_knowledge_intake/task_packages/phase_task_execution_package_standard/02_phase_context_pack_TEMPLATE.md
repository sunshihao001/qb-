# K00 知识资料摄取与任务化｜Context Pack

## 1. 本阶段为什么存在

用户输入的文档、知识资料、方法论文本不能被当成普通文档阅读。
它们可能是系统建设资料、阶段设计资料、规则升级资料、Atomic Skill 资料或旧系统迁移资料。

HER 必须先保存资料，再建立结构化任务包。

## 2. 本阶段不做什么

- 不直接做交易判断
- 不直接写买入卖出建议
- 不直接进入 P02-P05
- 不把聊天上下文当作长期记忆
- 不只写总结报告后停止

## 3. 本阶段必须做什么

- 保存原始资料
- 生成文档护照
- 生成系统映射
- 识别阶段影响
- 识别缺口
- 生成任务执行包
- 输出 handoff_packet
- 判断是否进入下一阶段

## 4. 本阶段完成标准

只有当原始资料、文档护照、系统映射、缺口列表、任务执行包、handoff_packet 全部生成后，本阶段才能进入 PHASE_READY。
