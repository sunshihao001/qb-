# HER 阶段自动展开协议

当用户只提供：总目标、当前阶段名称、当前阶段目标、阶段分层方向，HER 必须自动推导：输入、输出、字段、步骤、正向规则、反证规则、硬否决规则、状态码、验收、缺口、下游交接。

## 强制标记
- 自动补全：`系统推导`
- 缺失字段：`missing`
- 不确定内容：写入 `gaps.md`

## 执行顺序
读取总目标 → 阶段目标 → 阶段分类 → 层内步骤 → 输入合约 → 输出合约 → 字段 → 正证/反证 → 硬否决 → 状态码 → 验收 → 交接 → 审计。

## 证据链要求
任何阶段不得只输出支持结论；必须同时输出正向证据、反证、硬否决和证据链是否被否决的状态。证据链被反证击穿时，状态必须降级为 PAUSE/BLOCK/WAIT/REVIEW_ONLY。
