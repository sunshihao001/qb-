# 疑似主导侧成本区框架

## 目标

本框架用于在 Intel Structure Bot 内新增“疑似主导侧成本区与量化结构推断层”，只输出结构判断，不输出买点，不改状态机，不开启实盘。

## 核心边界

- 只做方法文档、字段设计和结构推断说明。
- 不直接使用“庄家成本”表述。
- 统一使用以下专业命名：
  - 疑似主导侧成本区
  - 疑似结构侧成本中枢
  - 结构侧筹码库存
  - 派发进度
  - 继续推进动机
  - 对手盘压力
- 所有对外 value 必须中文化。
- 交付对象是 Strategy Gate Bot，用于进一步寻找风险收益比合适的参与点。

## 设计目标

本层不再只寻找吸筹窗口，而是回答以下问题：

1. 疑似结构侧筹码是否仍在。
2. 疑似结构侧成本区在哪里。
3. 当前价格相对成本处于什么位置。
4. 派发是否已经完成。
5. 如果没出完，是否还有继续推进、二段扩张、控盘维护或制造流动性完成派发的动机。
6. 当前参与是否可能成为对手盘接盘。
7. 最终把结构判断交给 Strategy Gate Bot。

## 总体输出链路

1. 从钱包行为、同源关系、持仓分布、价格区间、成交集中区、回流路径中提取证据。
2. 计算疑似主导侧成本区。
3. 估计结构侧筹码库存。
4. 估计派发进度。
5. 估计继续推进动机与对手盘压力。
6. 判断钱包行为与盘型是否匹配。
7. 输出给 Strategy Gate Bot 作为前置结构解释层。

## 关键判断原则

### 1. 成本区不是单点
疑似主导侧成本区应被看作一个区间，而不是单一价格。

### 2. 成本区要看来源一致性
如果成本主要集中在同源组、早期结构钱包和高结果钱包，则更接近疑似主导侧成本区。

### 2.1 单钱包主动买入成本

对主动买入钱包，单钱包平均买入成本按以下公式计算：

```text
wallet_avg_cost = buy_amount_usd / buy_token_amount
```

必须读取或保留的字段：
- `wallet_address`
- `token_address`
- `buy_amount_usd`
- `buy_token_amount`
- `first_buy_time`
- `buy_count`
- `sell_amount_usd`
- `sell_token_amount`
- `current_balance`

输出字段：
- `wallet_avg_cost`
- `wallet_first_buy_cost`
- `wallet_last_buy_cost`
- `wallet_cost_confidence`

注意：
- 主动买入钱包可以估算成本。
- Token 转入钱包不能直接用转入价格当成本。
- 分发接收钱包成本未知，必须标记“成本不可直接确认”。

### 3. 成本区要看价格位置
当前价格是否明显高于、接近或跌破成本区，会显著改变结构解释。

### 4. 库存要看剩余可控筹码
若早期钱包、同源组或高结果钱包仍保有较高剩余比例，则说明结构侧筹码库存仍在。

### 5. 派发要看卖出路径
若卖出主要来自早期钱包和同源组，并且接收方逐渐转为晚期大额买入或浮亏钱包，则派发进度提升。

### 6. 动机要看是否值得继续维护
若库存仍多、成本未脱离、盘型仍可控、流动性承接良好，则可能仍有继续推进或二段扩张动机。

### 7. 对手盘压力要看是否出现接盘结构
如果晚期大额买入、接盘鲸鱼、散户化、早期筹码流向对手盘、浮亏钱包增加，则对手盘压力上升。

## 结论表达原则

- 只输出结构判断，不输出交易建议。
- 不直接说“可以买”或“应该买”。
- 只给出“结构侧是否仍在”“是否偏派发”“是否偏维护”“是否偏对手盘接收”的判断。

## 与 Strategy Gate Bot 的接口关系

本层负责：
- 提供成本区
- 提供库存状态
- 提供派发进度
- 提供继续推进动机
- 提供对手盘压力
- 提供钱包行为与盘型匹配度

Strategy Gate Bot 负责：
- 将结构判断映射为风险收益比筛选
- 决定是否进入后续门禁
- 决定是否继续观察、暂停或阻断

## 最小字段约定

建议最少包含以下对象：
- `dominant_cost_zone`
- `structure_inventory_estimate`
- `distribution_progress`
- `markup_motivation`
- `counterparty_pressure`
- `wallet_pattern_cost_alignment`

## 中文输出要求

所有 `*_zh` 字段必须为自然中文完整句，不得只放英文枚举。

## 结论

该层的任务是把“结构是否还在”“成本是否还在”“筹码是否还在”“派发是否接近完成”讲清楚，再交给 Strategy Gate Bot 做参与点筛选。
