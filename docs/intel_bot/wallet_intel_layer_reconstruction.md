# Intel Bot 钱包结构系统分层复原

## 1. GMGN 原始数据接收

旧系统以 GMGN 的 holders / traders / token candidate / cluster 相关导出作为事实输入，但当前保留下来的压缩包里主要保存的是导出结果与汇总件，而不是完整原始请求响应。

## 2. 字段标准化

标准化目标应是统一为 `wallet_structure_normalized` 这一类合同，而不是让中文展示字段直接进入后续分析。

## 3. 钱包实体画像

钱包应先被视为实体，再谈角色。实体画像应包含钱包年龄、新钱包标记、活跃度、标签、证据等级。

## 4. 当前代币行为

只分析当前 token 内的行为：首次买入、最后卖出、持仓、卖出比例、交易次数、ROI、PnL、Holder 排名等。

## 5. 资金路径与同源关系

关系层负责识别同源候选、同步行为、资金路径、分发、回流、基础设施边，而不是下结论为“庄家”。

## 6. 历史地址库

历史地址库把当前 token 的钱包行为映射到过去 token 复现中，以便支持复查和角色演化观察。

## 7. 评分与证据等级

分数只是门禁输入，不是交易指令。证据等级应高于标签，且要能被审计。

## 8. GMGN 备注输出

GMGN 备注是监控和复盘表达，不是交易建议。

## 9. 多轮快照 delta

需要比较多轮钱包结构快照，输出持仓变化、同步买卖变化、对手盘压力变化、迁移方向、质量变化。

## 10. wallet_structure_decision

`wallet_structure_decision` 是交易侧唯一交接文件。Intel Bot 只负责把证据和结构化判断装配好，不直接决定交易执行。
