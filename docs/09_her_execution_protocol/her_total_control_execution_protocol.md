# HER Total Control Execution Protocol

## Definition

Phase Controller 是可调度阶段运行单元，不是阶段说明文档；总控层负责路由、执行顺序、handoff 验证、状态继承、hard-negative 继承、目录宪法、contract/schema 索引、审计和专业验收。

## Protocol

1. Load total-control Skill.
2. Load goal, stage map, handoff flow, status codes, hard negatives, contract index, schema index.
3. Select Phase00-09 target, never Phase10.
4. Validate input contract.
5. Execute allowed tools/skills in paper-only boundary.
6. Write output contract artifacts.
7. Validate handoff schema.
8. Apply hard-negative/status inheritance.
9. Write audit evidence.
10. Advance only if gate allows.

## Forbidden

Private key, signing, broadcast, swap execution, auto real trade, invented facts, report-as-state.
