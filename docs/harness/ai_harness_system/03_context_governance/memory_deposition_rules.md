# 记忆沉淀规则

## 12.1 作用

把一次任务中的有效认知沉淀为以后可复用的系统资产。

## 12.2 记忆类型

```text
系统规则记忆
项目结构记忆
目录标准记忆
命令使用记忆
失败案例记忆
验证标准记忆
方法轮记忆
Bot 协作记忆
```

## 12.3 记忆不能写什么

```text
未验证猜测
一次性临时路径
错误命令
过期状态
重复废话
没有来源的结论
```

## 12.4 记忆写入格式

```text
记忆名称：
记忆类别：
适用系统：
来源任务：
核心内容：
证据文件：
验证状态：
下次调用方式：
失效条件：
```

## 12.5 原则

- 记忆必须来自已验证事实或已复盘经验。
- 记忆必须有来源。
- 记忆必须有适用范围。
- 记忆必须有失效条件。
- 记忆不能替代验证。
