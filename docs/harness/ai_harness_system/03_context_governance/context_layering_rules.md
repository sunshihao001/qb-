# 上下文分层规则

| 上下文类型 | 保存内容 | 是否长期保留 |
|---|---|---|
| 系统宪法 | 不变规则、边界、方法论 | 长期 |
| 项目记忆 | 当前项目目标、目录、模块 | 长期 |
| 任务记忆 | 当前任务进度、阶段状态 | 中期 |
| 会话记忆 | 本次对话发生的内容 | 短期 |
| 证据上下文 | 文件、截图、报告、日志 | 按任务保留 |
| 执行上下文 | 命令、输出、错误、测试结果 | 按运行保留 |
| 复盘上下文 | 失败原因、修正方案、经验 | 长期精选 |

## 禁止

- 不能把所有聊天都写入记忆。
- 不能把临时想法写成长期规则。
- 不能把失败结论当成最终事实。
- 不能把未验证内容写进系统宪法。
- 不能把过期文件路径当作长期路径。
