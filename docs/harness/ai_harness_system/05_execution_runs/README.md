# 05 Execution Runs

执行循环层负责让 AI 以循环方式推进任务，而不是一次性执行大任务。

## 8.1 核心原则

AI 不能一次性执行大任务。必须进入循环。

```text
接收目标
↓
读取上下文
↓
生成计划
↓
执行一段
↓
检查结果
↓
修正计划
↓
继续执行
↓
验证完成
↓
写入复盘
```

## 8.2 标准 Query Loop

```text
while 任务未完成:
    读取当前任务状态
    读取相关上下文
    检查上下文是否过载
    生成本轮最小执行单元
    执行本轮动作
    记录输出
    判断是否成功
    如果失败，进入恢复路径
    如果成功，进入验证路径
    更新任务状态
```

## 8.3 每一轮必须输出

```text
本轮目标
本轮输入
本轮执行动作
本轮输出文件
本轮验证结果
本轮问题
下一轮动作
```

## 8.4 作用

这套执行循环用于防止：
- Hermes 或 Bot 跑一会就停
- 任务只停留在表面文档
- 大目标一次性塞满上下文
- 执行过程没有状态
- 失败后没有恢复路径
- 成功后没有验证路径

## 8.5 写入要求

每次执行循环应至少记录：
- run log
- command log
- output 文件
- runtime state
- 本轮验证结果
- 下一轮入口
