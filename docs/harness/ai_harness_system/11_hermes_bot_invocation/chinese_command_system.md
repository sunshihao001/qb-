# 中文命令体系

> 方法轮补全路线图：`../02_research_loop/method_wheel_completion_checklist_v1.md`

```text
/目标登记
/系统侦察
/目录检查
/上下文整理
/任务拆解
/方法轮执行
/执行一轮
/验证结果
/错误恢复
/写入记忆
/生成复盘
/审计系统
```

## 自然语言隐式入口

用户没有输入上面的 slash command 时，Hermes 也不能退回自由聊天模式。自然语言必须先按 `../00_control_plane/natural_language_intake_protocol.md` 做隐式命令映射：

| 自然语言 | 等价命令 |
|---|---|
| “分析上面的内容” | `/目标登记` + `/方法轮执行` |
| “按 HER 底层设置” | `/目标登记` + `/任务拆解` + `/执行一轮` |
| “为什么没有默认处理” | `/错误恢复` + `/验证结果` |
| “哪些文档还缺” | `/系统侦察` + `/目录检查` |

## 命令作用

| 命令 | 作用 |
|---|---|
| /目标登记 | 把自然语言目标转成目标护照 |
| /系统侦察 | 读取当前目录、文件、上下文 |
| /目录检查 | 判断目录是否混乱 |
| /上下文整理 | 区分长期规则、任务状态、临时输入 |
| /任务拆解 | 生成阶段计划 |
| /方法轮执行 | 按研究助手流程深度分析 |
| /执行一轮 | 只执行当前阶段 |
| /验证结果 | 检查文件、命令、输出 |
| /错误恢复 | 分析失败并修复 |
| /写入记忆 | 把验证后的规则沉淀 |
| /生成复盘 | 输出任务总结 |
| /审计系统 | 检查是否只做表面 |
