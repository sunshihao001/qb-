# Memory Write Rules

## 用途
规定哪些内容可以沉淀为长期记忆，哪些不能。

## 适用范围
适用于系统规则、项目结构、目录标准、命令使用、失败案例、验证标准、方法轮、Bot 协作经验。

## 可写入
- 系统规则记忆
- 项目结构记忆
- 目录标准记忆
- 命令使用记忆
- 失败案例记忆
- 验证标准记忆
- 方法轮记忆
- Bot 协作记忆

## 禁止写入
- 未验证猜测
- 一次性临时路径
- 错误命令
- 过期状态
- 重复废话
- 没有来源的结论

## 检查标准
记忆必须包含：记忆名称、类别、适用系统、来源任务、核心内容、证据文件、验证状态、下次调用方式、失效条件。
