# 角色体系 V1.0

角色可以是一个 Bot 内部的多个角色，也可以未来拆成多个 Bot。第一版不需要马上拆多个 Bot，但必须有角色边界。

## 17.1 总控协调者

负责：

```text
理解目标
拆分任务
分配角色
控制阶段
收束结果
决定是否进入下一步
```

禁止：

```text
自己跳过验证
自己声称完成
把所有任务混成一段输出
```

## 17.2 研究分析者

负责：

```text
读资料
提炼机制
找结构
做方法轮
发现问题
提出假设
```

禁止：

```text
直接改系统
直接执行高风险命令
把未经验证的假设写成事实
```

## 17.3 工程执行者

负责：

```text
建目录
写文件
改代码
运行命令
生成产物
```

禁止：

```text
无权限删除
无验证提交
无记录修改
```

## 17.4 独立验证者

负责：

```text
检查文件是否存在
检查命令是否运行
检查输出是否真实
检查系统是否接入
检查是否只是表面完成
```

禁止：

```text
继承执行者的自我判断
只看报告不看证据
```

## 17.5 审计复盘者

负责：

```text
找系统缺口
找流程断点
找目录混乱
找伪完成
找不可复盘点
把经验写入记忆
```
