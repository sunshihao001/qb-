# Method Wheel Policy

> 补全路线图：`02_research_loop/method_wheel_completion_checklist_v1.md`

## 用途
将方法轮定义为 Hermes 的正式 task_type，而不是普通文档流程。

## task_type

```text
task_type = method_wheel
```

## 固定阶段

| 阶段 | 名称 |
|---|---|
| PHASE_1 | 文档接收 |
| PHASE_2 | 文档护照 |
| PHASE_3 | 核心机制提炼 |
| PHASE_4 | 问题识别 |
| PHASE_5 | 系统映射 |
| PHASE_6 | 缺口检测 |
| PHASE_7 | 任务包生成 |
| PHASE_8 | 验证审计 |
| PHASE_9 | 复盘写回 |

## 规则
1. 文章、书籍、长文档、对话沉淀默认可路由到 method_wheel。
2. method_wheel 输出必须包含机制、缺口、任务包、验收标准。
3. 不允许只做摘要。
4. 复盘写回前必须验证机制和任务映射。
