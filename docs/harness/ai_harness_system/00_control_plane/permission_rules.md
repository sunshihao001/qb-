# Permission Rules

## 用途
防止 AI 乱用命令、乱改文件、乱删目录、乱提交 Git、乱动运行数据。

## 适用范围
适用于所有工具调用、文件写入、命令执行与外部状态变更。

## 权限分级
| 权限级别 | 允许动作 | 是否需要确认 |
|---|---|---|
| 只读 | 列目录、读取报告、检查文件 | 不需要 |
| 分析 | 生成总结、计划、目录检查 | 不需要 |
| 写入低风险 | 新建文档、生成报告、创建草案 | 可自动 |
| 写入中风险 | 修改代码、改配置、重构目录 | 需要任务内授权 |
| 高风险 | 删除、移动大量文件、改生产数据 | 必须 ask |
| 不可逆 | git push、清空数据、覆盖历史 | 默认禁止 |

## 禁止行为
- 默认执行 `rm -rf`、`git push`、`git reset --hard`、`git clean -fd`。
- 批量移动未知文件。
- 覆盖配置文件。
- 删除日志和历史记录。
- 运行不明安装脚本。

## 检查标准
- 工具名称、命令内容、执行目录、输入输出、是否修改系统、权限检查、结果、错误、恢复动作必须可记录。
