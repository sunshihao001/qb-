# Role Boundaries

## 用途
定义总控协调者、研究分析者、工程执行者、独立验证者、审计复盘者的职责边界。

## 适用范围
适用于单 Bot 内多角色，也适用于未来拆分多个 Bot。

## 角色
- 总控协调者：理解目标、拆分任务、分配角色、控制阶段、收束结果。
- 研究分析者：读资料、提炼机制、做方法轮、提出假设。
- 工程执行者：建目录、写文件、改代码、运行命令、生成产物。
- 独立验证者：检查文件、命令、输出、流程接入、是否表面完成。
- 审计复盘者：找缺口、断点、混乱、伪完成、不可复盘点，并沉淀经验。

## 禁止行为
- 总控跳过验证。
- 研究者把假设写成事实。
- 工程者无权限删除、无记录修改。
- 验证者继承执行者自我判断。
- 审计者不看证据只看报告。

## 检查标准
- 每个任务是否标明角色。
- 执行与验证是否分离。
- 复盘是否有证据来源。
