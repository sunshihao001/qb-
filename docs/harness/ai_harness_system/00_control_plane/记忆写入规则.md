# 记忆写入规则

控制面规定哪些信息可以进入长期记忆，哪些不可以。

## 可以写入记忆的内容
- 用户稳定偏好
- 稳定目录规则
- 稳定系统架构
- 稳定环境事实
- 已确认的工作流经验
- 已验证的失败教训
- 系统规则记忆
- 项目结构记忆
- 目录标准记忆
- 命令使用记忆
- 失败案例记忆
- 验证标准记忆
- 方法轮记忆
- Bot 协作记忆

## 不可以写入记忆的内容
- 临时任务进度
- 当次会话草稿
- 未验证结论
- 一次性计划
- 当前窗口中的临时判断
- 可能很快失效的运行状态

## 写入原则
1. 只记录稳定事实。
2. 只记录可复用规则。
3. 只记录未来仍有价值的信息。
4. 记忆必须可替换、可删除、可索引。
5. 记忆不能替代验证。

## 写入时机
- 用户明确要求记住
- 系统发现稳定环境事实
- 发现稳定工作偏好
- 发现稳定运行规范

## 约束
- 不把聊天中的临时理解写成永久规则。
- 不把未完成的任务写入长期记忆。
