# 02 Research Loop

> 方法轮补全路线图：`method_wheel_completion_checklist_v1.md`

方法轮与研究资产目录。

## 6.1 作用

把一个大目标拆成可执行阶段。

不要让 AI 接到目标后直接写一大段，必须强制拆分：

```text
目标
↓
阶段
↓
模块
↓
步骤
↓
文件
↓
命令
↓
验证
↓
报告
```

## 6.2 标准分解模板

```text
任务分解/
├── 阶段 0：边界确认
├── 阶段 1：现状侦察
├── 阶段 2：问题识别
├── 阶段 3：系统映射
├── 阶段 4：方案设计
├── 阶段 5：执行计划
├── 阶段 6：验证计划
├── 阶段 7：风险审计
└── 阶段 8：复盘沉淀
```

## 6.3 每个阶段必须包含

- 阶段名称
- 阶段目标
- 输入来源
- 处理动作
- 输出文件
- 验收标准
- 失败处理
- 下一阶段入口

没有这些字段，就不能进入执行。

## 6.4 分解原则

- 先确认边界，再拆分阶段。
- 先看现状，再设计方案。
- 先识别问题，再写执行计划。
- 先定义验证，再进入执行。
- 先审计风险，再进入复盘。

## 6.5 输出要求

任务分解层至少要输出：
- 分解阶段列表
- 每阶段目标
- 每阶段输入来源
- 每阶段输出文件
- 每阶段验收标准
- 每阶段失败处理
