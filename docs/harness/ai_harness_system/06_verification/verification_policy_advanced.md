# Advanced Verification Policy

## 用途
将验证层从“检查文件存在”升级为结构、内容、流程、风险、证据的多段验证。

## 验证类型

| 验证类型 | 检查什么 |
|---|---|
| 结构验证 | 文件/目录是否存在、路径是否正确 |
| 内容验证 | 内容是否包含目标字段、禁止动作、验收标准 |
| 流程验证 | 是否被后续流程引用、是否不是孤立文档 |
| 风险验证 | 是否没有删除/覆盖/越权 |
| 证据验证 | 是否有日志、报告、状态文件支撑 |

## 三段核心验证
1. 结构验证：有没有、在哪里、目录对不对。
2. 内容验证：写了什么、字段是否完整、是否满足目标。
3. 流程验证：是否接入后续流程，不是孤立文档。

## 完成前要求
- 结构验证 PASSED。
- 内容验证 PASSED。
- 流程验证 PASSED 或明确标注未接入原因。
- 风险验证没有 DENY 级行为。
- 证据验证能追到日志、报告或状态文件。
