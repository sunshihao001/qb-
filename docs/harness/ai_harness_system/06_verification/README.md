# 06 Verification

验证审计层负责证明任务是否真的完成，而不是让 AI 自己声称完成。

## 10.1 核心原则

不能让 AI 说“我完成了”就算完成。必须有独立验证。

## 10.2 验证分级

| 验证类型 | 验证内容 |
|---|---|
| 文件验证 | 文件是否真实存在 |
| 内容验证 | 文件是否包含目标字段 |
| 结构验证 | 目录是否符合标准 |
| 命令验证 | 命令是否能运行 |
| 流程验证 | 上下游是否打通 |
| 数据验证 | 输出是否来自真实数据 |
| 复盘验证 | 是否能解释为什么成功/失败 |

## 10.3 完成定义

一个任务只有满足以下条件，才算完成：

```text
1. 目标已被拆解
2. 文件已真实生成
3. 关键命令已运行
4. 输出结果已检查
5. 错误已记录
6. 风险已说明
7. 下一步已明确
8. 复盘已写入
```

## 10.4 审计问题清单

```text
是否只是写了文档，没有接入流程？
是否只是建了目录，没有真实输出？
是否只是生成字段，没有数据来源？
是否只是写了命令，没有运行验证？
是否只是模型声称完成，没有证据？
是否把临时规则写成长期规则？
是否覆盖了旧数据？
是否有失败恢复路径？
```

## 10.5 验证输出要求

每次验证必须输出：
- 验证对象
- 验证方法
- 验证命令或检查方式
- 验证结果
- 失败项
- 风险说明
- 是否可宣布完成
