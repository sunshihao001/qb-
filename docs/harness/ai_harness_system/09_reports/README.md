# 09 Reports

报告复盘层负责让所有 AI 执行留下可复盘轨迹。

## 13.1 作用

所有 AI 执行都要留下可复盘轨迹。

不是为了好看，而是为了：

```text
以后知道为什么这么设计
知道哪个阶段失败
知道哪些文件是有效产物
知道哪些命令跑过
知道哪些东西只是草稿
知道下次从哪里继续
```

## 13.2 报告类型

```text
目标护照报告
侦察报告
系统设计报告
执行计划报告
运行日志报告
验证报告
错误恢复报告
复盘报告
记忆沉淀报告
```

## 13.3 每份报告必须包含

```text
任务编号
任务目标
执行时间
输入来源
执行阶段
输出产物
验证结果
失败点
风险点
下一步
```

## 13.4 报告原则

- 报告不是装饰，而是复盘入口。
- 报告必须说明哪些是有效产物，哪些只是草稿。
- 报告必须能指向证据文件。
- 报告不能替代验证。
- 报告必须说明下一步从哪里继续。
