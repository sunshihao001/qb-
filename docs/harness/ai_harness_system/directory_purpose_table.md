# Directory Purpose Table

| 目录 | 用途 | 禁止 |
|---|---|---|
| `00_control_plane/` | 控制面规则、系统宪法、权限、验证、恢复 | 禁止写临时任务状态 |
| `01_goals/` | 目标护照、原始用户目标 | 禁止直接放执行产物 |
| `02_research_loop/` | 方法轮、文档护照、缺口检测 | 禁止放业务 runtime 输出 |
| `03_context_governance/` | 上下文分层、记忆沉淀、证据索引 | 禁止把未验证猜测写成长期规则 |
| `04_task_plans/` | 阶段计划、任务状态机、执行包 | 禁止跳过验证进入 DONE |
| `05_execution_runs/` | 执行循环、工具调用记录、运行状态 | 禁止作为最终报告目录 |
| `06_verification/` | 文件/内容/结构/命令/流程/数据验证 | 禁止由执行者自证完成 |
| `07_recovery/` | 错误恢复、失败路径、重试计划 | 禁止把失败当完成 |
| `08_audit/` | 表面完成、系统缺口、完成质量审计 | 禁止只看报告不看证据 |
| `09_reports/` | 人类可读报告、复盘、最终总结 | 禁止替代验证 |
| `10_templates/` | 模板骨架 | 禁止把模板当真实运行结果 |
| `11_hermes_bot_invocation/` | Hermes/Bot 受控调用入口 | 禁止绕过目标护照直接执行 |
