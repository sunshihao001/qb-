# Global Hard Negative Rules

Hard negatives are inherited facts. A downstream score or narrative cannot erase them.

## Examples

- `DATA_INVALID`: invalid CA / broken snapshot / missing required fact.
- `WALLET_BLOCK`: wallet structure has blocking distribution/backflow/infra contamination.
- `ACTIVE_DISTRIBUTION`: distribution pressure dominates.
- `STRUCTURE_COLLAPSE`: early/control side no longer retains meaningful structure.
- `SCENARIO_TRAP_RISK`: trap/rug/exit-liquidity scenario is primary or insufficiently disproved.
- `COMPLETION_FAIL`: position completion missing when required.
- `FATIGUE_BLOCK`: prolonged fatigue invalidates timing.
- `POSITION_OVEREXTENDED`: entry position is structurally overextended.
- `EXECUTION_BLOCK`: quote/security/slippage/liquidity/risk check blocks execution.
- `REGRESSION_TEST_FAIL`: upgrade candidate failed regression.

## Enforcement

Phase06 and Phase07 must re-check the inherited list before any paper-ready decision.
