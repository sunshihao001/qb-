# HER Execution Protocol

## Default CA Run

When user asks to run a token/CA for effect review:

```text
resolve canonical token data
→ run wallet-structure intelligence
→ run chip/dealer-cycle/pattern intelligence
→ normalize evidence/counter-evidence/missing
→ pass into trade gate
→ Telegram concise report
→ write audit/handoff when needed
```

P01-P09 full file expansion is reserved for audit/regression/debug, not default Telegram UX.

## Safety

Always preserve: `real_trade_enabled=false`, `signing_enabled=false`, `broadcast_transaction=false`, `swap_enabled=false`, `max_real_position_sol=0`.
