# Global Status Code Table

## Purpose

统一 Phase00-09 状态码，禁止各阶段自定义状态码，保证 hard negative 与 degraded gap 能跨阶段继承。

## Global Handoff States

- `NOT_STARTED`: 尚未运行。
- `INPUT_READY`: 输入存在且可解析。
- `READY`: 必需字段、证据、反证、handoff、audit 均通过。
- `READY_WITH_GAPS`: 主流程可继续，但存在显式 missing/degraded，不可升级为强通过。
- `DEGRADED_CONTINUE`: 非阻塞缺口，允许继续但必须继承 gap。
- `BLOCKED`: 阻塞缺口或 hard negative，禁止下游正向解释。
- `OBSERVE_ONLY`: 仅观察，不允许 paper intent 以上动作。
- `PAPER_ONLY`: 仅纸面，不允许实盘。
- `REQUIRES_MANUAL_CONFIRMATION`: 需要人工确认；不能自动进入实盘。
- `BLOCK_REAL_TRADE`: 真实交易硬阻断。

## Phase Families

- P01: `DATA_FACT_READY`, `DATA_FACT_READY_WITH_GAPS`, `DATA_FACT_BLOCKED`
- P02: `WALLET_PASS`, `WALLET_PAUSE`, `WALLET_BLOCK`
- P03: `CONTROL_RETAINED`, `CONTROL_WEAK`, `CONTROL_LOST`, `ACTIVE_DISTRIBUTION`
- P04: `SCENARIO_PASS`, `SCENARIO_DEGRADED`, `SCENARIO_BLOCK`, `SCENARIO_TRAP_RISK`
- P05: `POSITION_PASS`, `POSITION_DEGRADED`, `COMPLETION_FAIL`, `FATIGUE_BLOCK`, `POSITION_OVEREXTENDED`
- P06: `STRATEGY_OBSERVE`, `PAPER_READY`, `STRATEGY_BLOCK`
- P07: `EXECUTION_OBSERVE`, `PAPER_TICKET_CREATED`, `EXECUTION_BLOCK`, `BLOCK_REAL_TRADE`
- P08: `REVIEW_READY`, `REVIEW_READY_WITH_GAPS`, `REVIEW_BLOCKED`
- P09: `UPGRADE_PACKAGE_READY`, `UPGRADE_PACKAGE_READY_WITH_GAPS`, `SYSTEM_UPGRADE_BLOCKED`

## Inheritance

上游 `*_BLOCK`、`ACTIVE_DISTRIBUTION`、`SCENARIO_TRAP_RISK`、`COMPLETION_FAIL`、`FATIGUE_BLOCK`、`POSITION_OVEREXTENDED`、`EXECUTION_BLOCK` 必须进入下游 `hard_negatives`。
