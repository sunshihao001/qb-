## Goal

Build a controllable, resumable, verifiable, auditable paper/observe trading research runtime for SIKK structural intelligence.

## Control definition

Phase Controller 是可调度阶段运行单元，不是阶段说明文档；总控层负责路由、执行顺序、handoff 验证、状态继承、hard-negative 继承、目录宪法、contract/schema 索引、审计和专业验收。

## Non-goals

- No real trade authorization.
- No private-key handling.
- No signing or broadcast.
- No swap execution.
- No Phase10 creation; total-control is a control layer, not a runtime phase.
