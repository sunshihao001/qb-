# Phase 05 Handoff Rules

- Upstream hard negatives dominate Phase05 positive evidence.
- `SCENARIO_BLOCK`, `SCENARIO_REVIEW_ONLY`, `SCENARIO_DISTRIBUTION_RISK`, `SCENARIO_TRAP_RISK` cannot produce `phase_06_strategy_gate_controller` handoff.
- `COMPLETION_PASS` requires at least two independent confirmations among AVWAP acceptance, Failure Test pass, POC support, volume confirmation, and no fatigue/overextension block.
- ADX/noise is only a filter; it cannot alone create a pass.
- Every handoff must include positive evidence, counter evidence, missing fields, hard-negative reasons, audit path, and required Phase06 context.
