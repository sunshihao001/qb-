# 15_judgment_governance

V1.6 Judgment Governance Layer stores artifacts that govern the quality of Hermes judgments, not just execution outputs.

## Subdirectories

- `runs/` — governance dry-run/runtime outputs.
- `templates/` — state/schema templates.
- `judgment_error_logs/` — judgment error tracking.
- `benchmark_cases/` — regression cases for judgment quality.
- `meta_verification/` — verification quality records.
- `anti_self_deception/` — false-closure audits.
- `causal_graphs/` — structured causal chains.
- `abstention_decisions/` — do-not-act / observe / handoff decisions.
- `solution_cost_reviews/` — complexity brake reviews.
- `memory_lifecycle_reviews/` — memory risk and staleness reviews.
- `operator_decision_records/` — human boundary records.

## Principle

A completed loop is not enough. The loop must be worth running, evidence-backed, non-self-deceptive, meta-verified, and safe to learn from.
