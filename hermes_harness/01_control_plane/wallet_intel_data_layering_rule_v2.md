# Wallet-Intel 数据分层规则 V2.0 — 阶段 3

## 1. 目标
让 Hermes 永久区送钱包数据的四个核心语义层：

```text
1. 钱包事实层
2. 结构证据层
3. 行为推断层
4. 策略交接层
```

本规则用于 Wallet-Intel 钱包数据采集分析、钱包结构分析、旧目录导入、字段字典、数据护照、handoff 包和导入后验证。

## 2. 四层定义

### 2.1 钱包事实层
记录可验证、可回溯、可直接引用的钱包事实数据。

包含：

```text
钱包地址
买入
卖出
持仓
资金来源
交易时间
余额变化
Top Holder 状态
Token 转入 / 转出
交易哈希
原始证据引用
```

规则：事实层可以直接引用，但不能写角色判断、动机判断或策略结论。

### 2.2 结构证据层
记录支持结构判断的证据，但不等于结论。

包含：

```text
同源证据
同步买卖
候选钱包组
资金路径
筹码分布
接盘路径
Token 转入来源
Top Holder 变化
K线阶段证据
GMGN/OKX/第二工具标签证据
```

规则：结构证据层必须带证据等级，并能追溯到事实层或原始证据。

### 2.3 行为推断层
记录基于事实与证据形成的行为解释或结构推断。

包含：

```text
主导侧生命周期
控筹状态
派发状态
二次扩张动机
对手盘压力
执行组候选
同源候选
接盘 / 套牢候选
风险观察
```

规则：行为推断层必须标注不确定性、证据等级、反向证据和失效条件。任何推断都不能写成确定事实。

### 2.4 策略交接层
记录给策略门禁、状态机、paper runner、dashboard、GMGN 备注或后续模块读取的 handoff 包。

包含：

```text
wallet_structure_handoff
paper_gate_handoff
state_machine_handoff
gmgn_remark_handoff
dashboard_handoff
review_handoff
next_module_read_contract
```

规则：策略交接层不能单独作为买入依据，只能作为后续模块的输入包。任何 SUPPORT / PAUSE / BLOCK 只作用于 paper / observe / review，不代表真实交易指令。

## 3. 强制规则

```text
规则 1：事实层可以直接引用。
规则 2：结构证据层必须带证据等级。
规则 3：行为推断层必须标注不确定性。
规则 4：策略交接层不能单独作为买入依据。
规则 5：任何推断都不能写成确定事实。
规则 6：所有结构判断必须能追溯到事实或证据。
规则 7：上一轮推断不能在下一轮变成事实。
规则 8：缺资金路径时不能强判同源。
规则 9：Top Holder 是事实，不等于控筹结论。
规则 10：handoff 是交接包，不是交易指令。
```

## 4. 层级引用关系

```text
钱包事实层 → 可直接引用
钱包事实层 + 结构规则 → 结构证据层
钱包事实层 + 结构证据层 + 方法规则 → 行为推断层
事实/证据/推断 + 动作边界 → 策略交接层
```

允许向上引用，禁止向下污染：

```text
证据可以引用事实；
推断可以引用事实和证据；
交接可以引用事实、证据和推断；
推断不能回写为事实；
交接不能回写为事实或证据。
```

## 5. 完成标准
Hermes 在处理任一 token 时，必须能回答：

```text
哪些字段是钱包事实？
哪些记录是结构证据？
哪些结论是行为推断？
哪些内容只是策略交接？
每个结构判断追溯到哪些事实或证据？
当前缺哪些事实或证据？
```
