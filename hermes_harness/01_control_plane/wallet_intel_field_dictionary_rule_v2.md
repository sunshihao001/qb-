# Wallet-Intel 字段字典规则 V2.0 — 阶段 5

## 1. 目标
Wallet-Intel 任务必须生成字段字典，并且字段字典必须中文化解释。字段字典不是简单字段清单，而是字段语义合同：告诉 Hermes 每个字段是什么、从哪里来、属于哪一层、给谁用、风险边界是什么。

## 2. 字段类型
字段至少分为五类：

```text
1. 事实字段
2. 统计字段
3. 结构证据字段
4. 行为推断字段
5. 策略交接字段
```

## 3. 每个字段必须包含的元数据

```text
字段名
中文名称
字段类型
字段来源
字段用途
是否事实字段
是否推断字段
风险边界
后续模块如何使用
```

## 4. 中文化规则

```text
字段字典中的解释必须使用中文。
字段名可保留英文原名，但必须配中文名称和中文用途说明。
缩写、标签、枚举值必须给出中文释义。
```

## 5. 关键约束

```text
same_source_group_id 只能解释为“疑似同源组编号”。
dominant_side_status 只能解释为“行为推断字段”，不能写成事实。
wallet_structure_decision 只能解释为“策略门禁输入”，不能写成结果事实。
WALLET_SUPPORT / WALLET_PAUSE / WALLET_BLOCK 不能被解释为直接买入信号。
```

## 6. 统一规则

```text
事实字段：描述可验证事件或状态，允许直接引用。
统计字段：描述汇总、计数、比例、排名、分位、变化率。
结构证据字段：描述支持结构判断的证据组合，必须有证据等级。
行为推断字段：描述对钱包行为或结构动机的解释，必须有不确定性。
策略交接字段：描述交给下游门禁/状态机/paper runner/ dashboard 的输入，不得单独构成买入依据。
```

## 7. 强制检查
字段字典生成后必须检查：

```text
字段是否能中文解释；
字段是否标明层级；
字段是否标明事实/推断属性；
字段是否说明风险边界；
字段是否说明后续模块怎么用；
是否存在将动作信号误写成交易建议的情况。
```

## 8. 禁止事项

```text
禁止把统计字段伪装成事实字段。
禁止把推断字段写成确定事实。
禁止把交接字段写成买入依据。
禁止把门禁动作解释为交易动作。
禁止把未知字段硬翻译成确定含义。
```
