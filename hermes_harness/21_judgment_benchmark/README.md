# 21_judgment_benchmark — V2.0 Judgment Benchmark

## 定位

V2.0 判断基准层，用于测试判断治理能力是否符合预期。

## 主要结构

- `benchmark_cases/`：判断样本。
- `expected_judgments/`：预期判断。
- `judgment_runs/`：执行结果。
- `judgment_error_logs/`：错误日志。
- `regression_reports/`：回归报告。

## 边界

此层是 benchmark skeleton。V2.1 的真实任务样本回放在 `23_real_task_regression/`。
