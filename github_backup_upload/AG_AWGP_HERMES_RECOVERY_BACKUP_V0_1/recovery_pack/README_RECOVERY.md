# AG-AWGP / Hermes Portable Recovery Pack v0.1

This pack implements Portable Recovery & Rehydration Strategy for Hermes / GBrain / OpenASE / AG-AWGP.

It is not a VPS zip and not a secret backup. It stores source-of-truth doctrine, operating profiles, workflow definitions, templates, restore scripts, verification scripts, manifests, and regression tests.

Hard forbidden: private keys, .env real values, API tokens, wallet secrets, signing material, live trading credentials.
