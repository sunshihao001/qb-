# O00_CLI_SAMPLE_REPLAY_READY_WITH_GAPS

## HER 文档到功能自动化落实系统：CLI 样例回放达标状态设计 v1.0

这个阶段不是继续新增理论模块，而是把前面设计的：

```text
controller_registry
pipeline_config
sample replay
O00 CLI / HER Command Entry
```

推进到一个真实可验收的系统状态：

```text
O00_CLI_SAMPLE_REPLAY_READY_WITH_GAPS
```

它的含义是：

```text
O00 CLI 已经能够读取 controller_registry、pipeline_config、sample replay，
能够创建 cli_run_id 和 pipeline_run_id，
能够执行一条 design-level sample replay，
能够输出 final report、trace、audit、gap register、acceptance matrix，
并且能够正确识别：当前只是 READY_WITH_GAPS，不能伪装成 PIPELINE_ACCEPTED。
```

---

# 1. 阶段总定义

## 1.1 状态名称

```yaml
status_code: O00_CLI_SAMPLE_REPLAY_READY_WITH_GAPS
status_family: PIPELINE_RUNTIME_VALIDATION_STATUS
phase_owner: O00_full_pipeline_orchestrator
entry_layer: O00_CLI_HER_Command_Entry
中文名称: O00 CLI 样例回放已跑通但仍带缺口
```

---

## 1.2 核心定义

```text
O00_CLI_SAMPLE_REPLAY_READY_WITH_GAPS 不是系统完全闭环完成。

它表示：

O00 CLI 入口已经具备最小可调度能力；
controller_registry / pipeline_config 可以被读取；
sample replay 可以被执行；
系统能够正确输出 READY_WITH_GAPS；
系统能够防止把设计、计划、样例回放误标为已实现、已测试、已运行、已治理生效。
```

也就是说，它验证的是：

```text
入口可调用
配置可读取
样例可回放
状态不伪装
trace/audit 可生成
gap 可保留
final report 可输出
```

而不是验证：

```text
真实功能全部实现
真实 pytest 已执行
真实 runner 已绑定
真实 policy 已 active
真实生产系统已接入
```

---

# 2. 这个阶段解决的核心问题

在此之前，系统还是：

```text
蓝图完整
配置完整
命令入口设计完整
但未证明 CLI 能跑一条样例
```

完成这个阶段后，系统进入：

```text
O00 CLI 具备 design-level replay 能力
```

它回答以下问题：

|问题|本阶段必须回答|
|---|---|
|O00 CLI 是否能启动？|必须|
|registry 是否能读取？|必须|
|config 是否能读取？|必须|
|sample replay 是否能读取？|必须|
|run_id 是否能创建？|必须|
|pipeline_state 是否能写入？|必须|
|trace / audit 是否能写入？|必须|
|final report 是否能生成？|必须|
|是否能正确输出 READY_WITH_GAPS？|必须|
|是否能阻止伪 TESTED / RUNNER_BOUND / POLICY_ACTIVE？|必须|

# 9. 最终状态判定规则

## 9.1 必须是 READY_WITH_GAPS 的原因

这条 sample replay 的目的不是证明所有工程实现完成，而是证明状态控制正确。

因此最终状态必须是：

```text
PIPELINE_READY_WITH_GAPS
```

对应：

```text
O00_CLI_SAMPLE_REPLAY_READY_WITH_GAPS
```

原因：

```text
1. sample replay 是 design-level replay。
2. 没有真实 pytest 执行证据。
3. 没有真实 runner dry-run 证据。
4. G00 只生成 governance candidate，不激活 active policy。
5. 部分 controller 仍然是 DESIGN_ONLY。
6. 系统能正确保留这些 gap。
```

---

## 9.2 禁止最终状态

```text
PIPELINE_ACCEPTED
SYSTEM_FULLY_IMPLEMENTED
FUNCTION_IMPLEMENTED
TESTED
RUNNER_BOUND
POLICY_ACTIVE
PRODUCTION_READY
```
