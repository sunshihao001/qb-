# Acceptance Storage Constitution

建议数据目录：`/root/sikk-gmgn/data/acceptance_plane/`。

- acceptance_results: 机器可读验收结果
- acceptance_reports: 人类可读报告
- acceptance_gates: 验收门执行记录
- acceptance_scores: 评分明细
- acceptance_gaps: 缺口登记
- acceptance_blocking_events: 阻断事件
- acceptance_rework_tasks: 返工任务
- handoff_permissions: 下游交接权限
- audit: 审计记录
