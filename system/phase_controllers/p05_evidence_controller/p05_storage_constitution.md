# P05 Storage Constitution

## System files
`/root/sikk-gmgn/system/phase_controllers/p05_evidence_controller/` stores controller package files, contracts, schemas, policies, acceptance criteria, and HER protocol.

## Runtime data
`/root/sikk-gmgn/data/phase_controllers/p05_evidence/` stores runtime evidence packages. Subdirectories:

- `input_manifest/`
- `evidence_subjects/`
- `hypothesis_frames/`
- `evidence_objects/`
- `supporting_evidence/`
- `counter_evidence/`
- `weak_evidence/`
- `unknown_evidence/`
- `conflicts/`
- `alternative_explanations/`
- `evidence_chains/`
- `evidence_weights/`
- `evidence_bundles/`
- `sufficiency/`
- `usage_permissions/`
- `quality/`
- `gaps/`
- `p06_data_requests/`
- `rejected_candidates/`
- `blocked_candidates/`
- `trace/`
- `acceptance/`
- `handoff/`
- `reports/`
- `audit/`

Runtime data directories are skeletons only in this package landing; no paper/live execution is authorized.
