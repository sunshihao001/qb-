# P05 Acceptance Criteria

## P05_READY / P05_READY_FOR_P06_HANDOFF
- P04 handoff present and accepted.
- evidence input manifest, subject registry, hypothesis frames, evidence objects, counter/weak/unknown/conflict records, alternative explanations, chains, weights, bundles, sufficiency, usage permissions are present.
- P06 scenario data request and P05→P06 handoff contract exist.
- No scenario claim, strategy signal, paper_ready, paper runtime, or live execution.

## P05_READY_WITH_GAPS
Allowed only when gaps are non-runtime and explicitly propagated to P06 as limitations.

## P05_REJECTED
No usable evidence input, all source records untraceable, or evidence object contract unavailable.

## P05_BLOCKED
Missing P04 handoff/trace/acceptance, bypassed handoff plane, ignored counter-evidence/conflicts, weak evidence promoted, or any strategy/paper/live output.
