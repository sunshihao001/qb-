# HER P05 Execution Protocol

1. Read professional build order / phase index / P05 context.
2. Read P04→P05 handoff and P05 evidence data request.
3. Read Trace / Acceptance / Handoff outputs and field permissions.
4. Build input manifest, subject registry, hypothesis frames.
5. Qualify source material trace and permissions.
6. Generate evidence objects, supporting evidence, counter evidence, weak evidence, unknown evidence, conflicts, alternative explanations, chains, weights, bundles.
7. Check sufficiency and usage permissions.
8. Generate gap report, P06 scenario data request, trace, report, P05→P06 handoff.
9. Run acceptance.
10. Handoff only to P06.

Forbidden: no P04 handoff bypass, no trace-free evidence, no fact→scenario promotion, no support-only evidence, no ignored conflict, no weak→strong promotion, no scenario/strategy/paper_ready, no paper runtime, no live execution.
