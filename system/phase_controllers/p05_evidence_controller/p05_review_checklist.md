# P05 Review Checklist

- [ ] P04 handoff was read.
- [ ] Source trace and field trace exist for every evidence object.
- [ ] Every evidence object binds a hypothesis frame.
- [ ] Supporting evidence has counter-evidence check.
- [ ] Unknowns are explicit, not filled with assumptions.
- [ ] Conflicts are preserved and propagated.
- [ ] Alternative explanations are recorded where facts are multi-interpretable.
- [ ] Evidence weights preserve dimensions; no single total score hides reasoning.
- [ ] Usage permissions forbid P07/paper/live direct use.
- [ ] P06 request and handoff packet are created.
