# P04 Acceptance Criteria

PASS_WITH_RUNTIME_GAPS requires all package files parse, all required schemas/policies exist, P04 boundaries hold, and runtime remains blocked.

P04_READY_WITH_GAPS is allowed only for package/design readiness or later runtime structure outputs with explicit supply/accounting/cohort limitations transferred to P05.

P04 must be BLOCKED if it confirms controller/market maker, creates evidence objects, outputs scenario/strategy/paper permission, or enables live execution.
