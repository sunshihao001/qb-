# P03 Acceptance Criteria

PASS_WITH_RUNTIME_GAPS requires all package files parse, all required schemas/policies exist, safety anchors hold, and runtime remains blocked.

P03_READY_WITH_GAPS is allowed only for runtime data processing after P02 handoff exists and missing funding/history/calibration gaps are explicitly transferred to P04.

P03 must be BLOCKED if it confirms market maker/dominant side, outputs chip control, scenario, strategy, paper permission, or enables live execution.
