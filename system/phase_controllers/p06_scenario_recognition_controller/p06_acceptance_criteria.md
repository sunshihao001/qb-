# P06 Acceptance Criteria

- P06_READY_FOR_P07_HANDOFF: package outputs complete and accepted; runtime still blocked.
- P06_READY_WITH_GAPS: usable for P07 with limitations; conflicts/unknowns propagated.
- P06_REJECTED: critical inputs missing or all evidence unusable.
- P06_BLOCKED: handoff/trace/safety/hard-negative violation.

Never mark paper/live/runtime ready.
