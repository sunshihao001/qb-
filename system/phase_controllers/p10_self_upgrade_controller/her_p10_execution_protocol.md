# HER P10 Execution Protocol

1. Read professional build order and phase controller index.
2. Read P10 context.
3. Read P09→P10 handoff and upgrade candidate data request.
4. Build upgrade input manifest.
5. Review upgrade candidates.
6. Assess sample support, overfit risk, impact and compatibility.
7. Build schema/rule/parameter/test/tool/runtime/report proposals.
8. Build upgrade decisions.
9. Build regression test plan.
10. Build release and rollback plan.
11. Build approval requirements.
12. Build controlled upgrade package and task packet.
13. Update backlog and trace.
14. Generate report and implementation handoff.
15. Execute acceptance.

Forbidden: no direct rule mutation, no auto deploy, no paper runtime, no live execution, no wallet signing, no bypass of Governance/Acceptance/rollback.
