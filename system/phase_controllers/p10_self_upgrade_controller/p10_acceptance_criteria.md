# P10 Acceptance Criteria v3.0

## P10_READY
- P09 handoff accepted and traceable.
- Upgrade input manifest, candidate review, sample support, classification, impact, overfit, compatibility, proposals, decisions, regression plan, release/rollback plan, approval requirements, controlled package, task packet, version change, backlog, handoff contract all exist.
- Runtime, paper runtime, live execution, wallet signing and auto deploy are false.

## P10_READY_WITH_GAPS
- Controller package complete, but runner/CI/dry-run/governance tooling is not bound.

## P10_REJECTED
- Missing upgrade candidate, invalid scope, or unsupported upgrade class.

## P10_BLOCKED
- Missing P09 handoff, direct rule mutation, auto deploy, no regression plan, no rollback plan, paper runtime, live execution, or wallet signing.
