# Knowledge Processing Acceptance Criteria

必须存在：document passport、document type classification、semantic chunking、concept extraction、functional object extraction、system mapping、controller candidate、schema/contract candidate、HER task package、acceptance result、handoff packet。

必须满足：所有结论有 source trace；所有任务有输入、输出、验收标准、禁止事项；所有生产变更均为 candidate-only；有 gap report；有 handoff target。
