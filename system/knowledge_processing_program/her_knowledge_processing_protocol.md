# HER Knowledge Processing Protocol

当用户上传文档、方法论、系统设计、运行报告、任务指令时，HER 必须进入 K00-K08：保存 raw → passport/classification → semantic chunks → concepts/methods/assumptions/constraints/gaps → functional objects → system mapping → candidates → HER task package → acceptance → handoff → index。

不得以“总结文档”结束。不得直接修改生产系统。不得无 trace / acceptance / handoff 输出结论。
